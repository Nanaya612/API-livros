# API livros
Uma API simples para catalogar livros, feita com Python e FastAPI que simula funções de requisições assíncronas

# Instalação
1. Pré-requisitos:

    * Python 3.4 ou maior
    * FastAPI na versão 0.139.0 ou maior

2. Clone o Reposítorio
    
    * Utilize o comando `git clone https://github.com/Nanaya612/API-livros`
    * Depois utilize `cd API-livros`

3. Inicie a aplicação

    * Utilize o comando `fastapi dev main.py` para iniciar a aplicação
    * Faça as requisições pelo endpoint `http://127.0.0.1:8000`
